# Campaign Loop — بسته‌ی تحویل به Claude Code

## داخل بسته چیست
- `PROMPT.md` — پرامپت کامل ساخت محصول (۱۳ مرحله). همین را به Claude Code بدهید.
- `CLAUDE.md` — قواعد ثابت پروژه؛ Claude Code خودکار می‌خواند.
- `design/` — نمونه‌ی کامل و کارکردی محصول (پنل، لندینگ، حقوقی، ایمیل‌ها، کیت رابط، نقشه‌ی خدمت) + لوگوها.
- `docs/` — مشخصات فنی: مدل داده و API، فرانت، بک‌اند، هوش مصنوعی با متیس، اتصال ادتریس و اینترک، توکن‌ها، کیس‌های تست.
- `engine/` — موتور محاسبه‌ی استخراج‌شده با تست.
- `fixtures/` — داده‌ی دمو و مجموعه‌ی ارزیابی هوش مصنوعی.
- `product/` — PRD و سیستم دیزاین اسمارتک.
- `env.example` — همه‌ی متغیرهای محیطی.

## شروع
1. پوشه را از زیپ باز کنید و داخلش `git init` بزنید.
2. Claude Code را در همین پوشه باز کنید.
3. کل محتوای `PROMPT.md` را به‌عنوان پیام اول بفرستید.
4. بعد از هر مرحله، Claude Code متوقف می‌شود و نتیجه را نشان می‌دهد؛ تأیید کنید تا ادامه دهد.
5. در مرحله‌ی M7 کلید متیس را می‌خواهد: `env.example` را به `.env` کپی کنید و `AI_PROVIDER=metis`، `METIS_API_KEY` و نام مدل‌ها را وارد کنید. آدرس پایه و نام مدل‌ها را از پنل متیس تأیید کنید.
6. کلید ادتریس و اینترک را هر وقت آماده شد در مرحله‌ی M9 بدهید؛ تا آن موقع با داده‌ی شبیه‌سازی کار می‌کند.

## نکته
کلیدها را هرگز داخل کد یا چت عمومی نگذارید؛ فقط در `.env`.
